My C Dev Notes

本站用于记录我在学习 C 语言与底层开发过程中的笔记、代码片段和踩坑经验。内容以 C 为主，偶尔涉及汇编、操作系统和编译原理。

为什么选择 C

C 语言贴近硬件、没有隐藏开销，是理解计算机系统最好的入口之一。无论是操作系统、嵌入式，还是高性能中间件，C 依然是绕不开的基础。

一个最小示例

下面是一个用 C 实现的简单链表节点定义与遍历示例：

#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;
} Node;

Node *push(Node *head, int v) {
    Node *n = malloc(sizeof(Node));
    if (!n) return head;
    n->value = v;
    n->next = head;
    return n;
}

void print_list(Node *head) {
    for (Node *p = head; p; p = p->next)
        printf("%d ", p->value);
    printf("\n");
}

int main(void) {
    Node *list = NULL;
    for (int i = 1; i <= 5; i++)
        list = push(list, i);
    print_list(list);
    return 0;
}
